# Shared Services

Reusable technical integrations used by multiple business modules.

Shared services provide capabilities; they do not make EFPS business decisions.

## Folders

- `google_sheets/` — reusable Google Sheets technical capabilities.
- `cloudinary/` — reusable Cloudinary media capabilities.
- `whatsapp_whapi/` — reusable WhatsApp/WhAPI connectivity and API capabilities.
