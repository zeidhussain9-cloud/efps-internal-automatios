# Session Start Skill

Use this at the beginning of every EFPS Internal Automations development session.

## Mandatory steering

Apply `CORE_STEERING.md` before any response or action, including a one-word iteration or continuation request.

## Steps

1. Apply `CORE_STEERING.md` and establish the exact user request.
2. Read `GEMINI.md`, `AGENTS.md`, and `HANDOFF.md`.
3. Read the relevant canonical documents in `docs/`.
4. Read the relevant module or shared-folder `GEMINI.md` and `README.md`.
5. Establish the current repository state from the actual files and code and verify any required runtime or external facts.
6. Identify unknowns or conflicts; do not guess.
7. Restate the immediate work plan in plain language before significant implementation.

## Principle

Start from current verified repository truth, not memory or assumption.
