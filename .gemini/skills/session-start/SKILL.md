# Session Start Skill

Use this at the beginning of every EFPS Internal Automations development session.

## Steps

1. Read the root `GEMINI.md` and `HANDOFF.md`.
2. Read the relevant module or shared-folder `GEMINI.md` and `README.md`.
3. Read `docs/architecture.md` and `docs/data-contracts.md` when the task crosses boundaries.
4. Establish the current repository state from the actual files and code before making changes.
5. Restate the work plan in plain language before implementation.
6. Do not guess when repository evidence can establish the fact.

## Principle

Start from current repository truth, not from memory of a previous session.
