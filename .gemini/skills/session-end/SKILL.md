# Session End Skill

Use this at the end of every EFPS Internal Automations development session.

## Steps

1. Review the files changed in the session.
2. Verify that implementation and documentation still agree.
3. Update `HANDOFF.md` so it reflects the current working state.
4. Update `docs/architecture.md`, `docs/data-contracts.md`, or the relevant folder README when actual ownership or behavior changed.
5. Validate the work that can be validated at the current stage.
6. Confirm the resulting commit/state before declaring the task complete.

## Principle

A task is not complete when code exists but the repository documentation and current state are inconsistent.
