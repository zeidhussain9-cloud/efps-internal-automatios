# CRM Deterministic Classification Engine

> Verified 2026-10-04 01:19 IST against production Supabase and the live Render release.

## Purpose

The deterministic engine classifies WhatsApp contacts without AI. It evaluates the accumulated conversation for production source +919148338801 and makes only evidence-backed decisions.

## Storage model

- crm_webhook_events: durable webhook/event evidence and raw normalized payload.
- crm_messages: chronological conversation messages.
- crm_contact_classifications: current contact queue/classification state.
- crm_activity: automatic decision/audit provenance.
- crm_deterministic_scheduler_runs: scheduler execution history.
- crm_leads.auto_qualified: persisted provenance for deterministic Qualified Leads.

## Pending-contact lifecycle

New messages for a pending contact continue attaching to the same classification record and are appended to crm_messages. The deterministic scheduler reevaluates the accumulated conversation when new evidence is available.

## Decision model

1. Hard exclusions: persisted WhatsApp group chat evidence (@g.us), operator-confirmed Internal, Personal / Family, Agent / Partner, Vendor / Supplier, and other existing operator-controlled exclusions.
2. Qualification Gate A: customer-originated intent.
3. Qualification Gate B: property or requirement evidence.
4. Gate A + Gate B: Qualified Lead.
5. Supported deterministic Unqualified evidence: Group Message, Agent / Partner, Vendor / Supplier, Promotion / Marketing, Cold Inquiry and existing controlled categories where explicitly supported.
6. Insufficient evidence: remain Waiting for Classification.
7. Property Listing Sent is legacy historical data only and is never generated by this engine.

## Direction and context rules

- Outbound EFPS property/listing messages alone cannot qualify a contact.
- Outbound property context may support Gate B when a customer subsequently supplies qualifying intent.
- Qualification is conversation-level and can combine evidence from multiple messages.
- Listing-site URLs are property context, not Agent/Partner evidence by themselves.
- Phone numbers are not treated as budget/price evidence.

## Scheduling

Supabase Cron job crm_deterministic_scheduler_1h runs at 0 * * * *.

The scheduler:
- processes pending contacts whose conversation changed since the last deterministic evaluation;
- prevents overlapping runs with a PostgreSQL advisory lock;
- records scheduler results;
- performs no AI calls.

## Automatic qualification provenance

A deterministic Qualified Lead is persisted with classification_source=deterministic_rule, deterministic rule version, evidence message IDs, evidence webhook event IDs, reason/signals, audit activity, and crm_leads.auto_qualified=true. The UI renders AUTO QUALIFIED on the lead card.
